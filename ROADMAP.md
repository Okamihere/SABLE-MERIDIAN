# Roadmap — SABLE MERIDIAN

This file is kept at the project root for contributors and the static validator.
The phase overview also lives in [docs/roadmap.md](docs/roadmap.md).

## Completed prototype phases

- [x] Third-person movement, camera, jump and wall movement
- [x] Hitboxes, health, combos, launchers, aerial attacks and dodge
- [x] Basic enemies, style ranks, training room and gothic city blockout
- [x] Responsive HUD and collectible wall-jump upgrades
- [x] Integrate the supplied jester model as the playable character with a procedural rig

## Next phases

- [ ] Author polished character animations and improve blend transitions
- [ ] Add target switching while locked on and unlockable double jump
- [ ] Expand the playable weapon roster, combo trees and enemy archetypes
- [ ] Add navigation and boss encounters
- [ ] Add pooled effects, trails, audio and music layers
- [ ] Add checkpoints, a complete campaign save and remappable controls; orb progress and settings already persist
- [ ] Profile performance on target hardware and improve the city art
