# Contributing to SABLE - MERIDIAN

Thanks for your interest in contributing! This is a Godot 4.x game project.

## Getting Started

1. **Fork** this repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/SABLE-MERIDIAN.git`
3. **Create a branch**: `git checkout -b my-contribution`
4. **Open in Godot 4.x** and verify everything works
5. **Make changes** and test in the editor
6. **Commit** with clear messages
7. **Push** to your fork
8. **Open a Pull Request**

## What You Can Contribute

- **Bugs** — find and fix issues
- **Features** — new mechanics, enemies, levels
- **Design** — visuals, animations, effects
- **Audio** — sounds or music
- **Translation** — other languages
- **Tests** — add validations

## Rules

- **Test before PR** — project must compile and run without errors
- **Keep the style** — GDScript with tab indentation
- **Small commits** — one thing at a time
- **Describe your PR** — what, why, and how to test

## Project Structure

```
SABLE-MERIDIAN/
├── scenes/          # Game scenes
├── scripts/         # GDScript files
├── resources/       # Sprites, sounds, materials
├── effects/         # Visual effects
├── materials/       # Godot materials
├── tools/           # Test & validation tools
└── project.godot    # Project configuration
```
